# Agent instructions

This repository is a skill for building, fixing, and reviewing slide decks. It is not a product deck and it has no brand.

1. Read `SKILL.md` before any slide work.
2. Follow the workflow in that file, in order.
3. Before you deliver, run `python scripts/check_deck.py` on the `.pptx` and `bash scripts/render_preview.sh` to render every slide. Look at each PNG. Do not send a deck that fails the checker or that you have not looked at.
4. Use `references/writing-guide.md`, `references/readability.md`, `references/canva-and-shared-decks.md`, and `references/style-directions.md` when the copy, the type, a shared deck, or the art direction needs more detail.
5. Keep Vietnamese diacritics intact. The default body font is Be Vietnam Pro. Do not set Vietnamese text in Anton.
6. Do not invent figures. Do not overwrite a shared deck. Do not group or flatten text.
